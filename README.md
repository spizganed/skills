# skills

Four Claude Code skills. Each skill is one short file.

| Skill | Effect |
|---|---|
| `yagni` | Build only what the task needs. |
| `ooga-bogga` | Terse chat replies. No filler. |
| `asd-ste100` | Simplified Technical English for all text. |
| `ui-ux` | UI checks. Loads only on UI work. |

## Install

```sh
cp -r yagni ooga-bogga asd-ste100 ui-ux ~/.claude/skills/
```

Restart Claude Code.
